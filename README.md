# Cali.app — AI Fitness Assistant

## Проблема
Заниматься без тренера — значит не знать, правильно ли выполняешь упражнение. Ошибки техники ведут к травмам и слабому результату.

## Решение
Cali.app работает прямо в браузере: смотрит через камеру, считает повторения и подсказывает, что именно исправить — без сервера и регистрации.

## Возможности
- Real-time распознавание через веб-камеру, skeleton поверх видео
- 3 упражнения: Squat, Push-up (повторения), Plank (время удержания)
- **Error Mode** — конкретные подсказки вместо «Incorrect»
- Защита от фейков: при низкой уверенности повторения не считаются
- Итог тренировки: упражнение, повторения, длительность, оценка техники
- **Приветственная страница** с разделами «О проекте», «Миссия», «Возможности»
- **Редактирование текстов** приветствия (сохраняется в localStorage)
- **Переключатель языков** RU / EN
- Адаптивный интерфейс камеры (телефон / планшет / ПК), fullscreen, смена камеры

## Технологии
HTML, CSS, JavaScript (ES-модули), MediaPipe Pose (CDN). Без React, Node, backend и сборки.

## Архитектура
Camera → Pose Detection → Landmarks → Movement Analysis → Error Detection → Feedback → Workout Result

| Файл | Ответственность |
|---|---|
| `app.js` | связывает модули, главный цикл |
| `js/camera.js` | запуск/остановка камеры |
| `js/pose.js` | MediaPipe → landmarks, skeleton |
| `js/exercises.js` | углы, state machine, повторения |
| `js/errorMode.js` | метрики → подсказки |
| `js/workout.js` | состояние тренировки |
| `js/ui.js` | интерфейс, welcome, i18n-применение |
| `js/i18n.js` | строки RU/EN, переключатель |
| `js/content.js` | советы и summary |
| `utils/*` | математика и пороги |

## Запуск
Камера работает только по **https** или **localhost**.
```
cd Cali.app
python3 -m http.server 8000
# открой http://localhost:8000
```
